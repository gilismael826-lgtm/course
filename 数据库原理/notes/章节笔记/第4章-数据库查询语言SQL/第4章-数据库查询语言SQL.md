## 重点内容

### ⭐⭐⭐ 核心内容
- **SQL数据定义**：CREATE / ALTER / DROP 创建、修改和删除数据库对象（表、视图、索引等）
- **SQL数据查询**：SELECT语句的各种用法（单表查询、连接查询、子查询、聚合查询）
- **SQL数据操纵**：INSERT / UPDATE / DELETE 实现数据的插入、更新和删除

### ⭐⭐ 重要概念
- **SQL概述**：SQL的发展历程、特点和基本功能（DQL/DML/DDL/DCL）
- **SQL数据类型**：字符串型、数值型、日期时间型、货币型、二进制型等
- **视图**：虚表，基于查询结果的逻辑表，不实际存储数据

### ⭐ 基础概念
- **SQL标准演进**：SQL-86 -> SQL-89 -> SQL-92 -> SQL-99 -> SQL-2003
- **SQL的三级模式支持**：外模式（视图）、模式（基本表）、内模式（存储文件）
- **自定义数据类型**：通过 CREATE TYPE 定义用户所需的数据类型
