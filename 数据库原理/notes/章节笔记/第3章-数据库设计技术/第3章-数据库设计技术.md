## 重点内容

### ⭐⭐⭐ 核心概念
- **数据库设计的六个步骤**：需求分析 -> 概念结构设计 -> 逻辑结构设计 -> 物理结构设计 -> 数据库实施 -> 运行和维护
- **概念结构设计**：用E-R图描述现实世界的实体及其联系，是数据库设计的关键环节
- **逻辑结构设计**：将E-R图转换为关系模式，结合第2章规范化理论进行优化

### ⭐⭐ 重要概念
- **数据库设计的目标**：满足用户需求 + 简化应用编程、实现高效开发、减少成本
- **数据库设计的特点**："认识-设计-纠正-认识"的反复求精过程，不是"一次到位"
- **需求分析**：系统调研、SA方法、数据流图、数据字典

### ⭐ 基础概念
- **物理结构设计**：为逻辑模型选取合适的存储结构和存取方法
- **数据库实施**：创建数据库、载入数据、编码调试、试运行
- **运行和维护**：数据库投入运行后的持续监控、调整和优化
