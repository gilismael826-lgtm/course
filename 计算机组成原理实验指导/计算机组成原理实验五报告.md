# 二、实验原理

## 2.1 存储器的分类

根据在计算机系统中的作用，存储器可分为主存储器、辅助存储器、缓冲存储器。

**主存储器（主存）**的主要特点是它可以和 CPU 直接交换信息。主存拥有速度快、容量小、每位价格高的特点。

**辅助存储器（辅存）**是主存储器的后援存储器，用来存放当前暂时不用的程序和数据，它不能与 CPU 直接交换信息。

**缓冲存储器（缓存）**用在两个速度不同的部件之中，例如 CPU 和主存之间可以设置一个快速缓存起到缓冲作用。

## 2.2 DM1000 中的 MEM 模块

在 DM1000 中，存储器模块 MEM 扮演主存储器的角色，它用来存储指令和数据，可以读或写。

### MEM 模块的主要功能：

**（1）读功能**：从存储器读取指令或数据
- 当 MEM_WR 为高电平时，RAM 总是输出地址指定单元的内容
- 通过 MEM_GATE_EN 控制输出门，将数据传送到数据总线

**（2）写功能**：将程序执行过程中的数据或地址信息写入存储器
- 当 MEM_WR 为低电平时，在输入时钟上升沿的触发下，可将数据写入存储器
- 写入的地址由地址总线 ABUS 提供，数据由数据总线 DBUS 提供

### MEM 模块端口说明：

| 端口名称 | 方向 | 功能说明 |
|:--------:|:----:|:---------|
| ABUS[7..0] | 输入 | 地址总线，为访问存储器提供 8 位地址 |
| DBUS[7..0] | 双向 | 数据总线，传输读写的 8 位数据 |
| MEM_WR | 输入 | 读写控制信号，低电平写，高电平读 |
| MEM_GATE_EN | 输入 | 存储器输出门使能，低电平有效 |
| CLK | 输入 | 时钟信号，写操作在上升沿触发 |

### MEM 模块电路结构：

MEM 模块内部主要包含：
1. **RAM 存储器**：256 字节存储容量，8 位数据线，8 位地址线
2. **地址输入缓冲**：接收来自地址总线的地址信号
3. **数据输入/输出缓冲**：双向数据传输
4. **输出门 MEM_gate**：控制存储器数据是否输出到数据总线

## 2.4 存储器在指令执行中的作用

在 DM1000 模型机中，存储器在指令执行过程中承担三种访问方式：

### （1）取指令
- 所有指令执行的第一步
- PC 提供指令地址 → 存储器输出指令 → 指令送入指令寄存器 IR
- 控制信号：PC_A_GATE_EN=0, MEM_GATE_EN=0, MEM_WR=1

### （2）读数据
- 对于包含立即数的指令，需要再次访问存储器
- PC 提供数据地址 → 存储器输出数据 → 数据送入目的寄存器
- 例如：mov a, 7 指令需要读出立即数 7

### （3）写数据
- 将寄存器中的数据写入存储器
- 寄存器提供数据 → 存储器接收数据并写入指定地址
- 例如：mov [r2], a 指令将累加器 a 写入 r2 指向的单元

| 3 | path r2, mar | r2→MAR | - | r2→MAR |

### （4）实验任务总结

通过本任务的仿真，深入理解了存储器在程序运行过程中的重要作用：

1. **取指令**：所有指令执行的第一步都是从存储器中取出指令。PC 提供指令地址，存储器输出指令到数据总线，CU 模块接收指令并译码，同时 uPC 跳转到该指令对应的微程序入口。

2. **读数据**：对于包含立即数的指令，需要从存储器中读出操作数。例如 `mov a, 7` 指令，在取指后需要再次访问存储器读出立即数 7。此时 PC 已经加 1，指向立即数所在的存储单元。

3. **写数据**：`mov [r2], a` 指令将累加器 a 中的数据写入 r2 指向的存储单元，实现了数据向存储器的回写。这是存储器写操作的典型应用。

4. **地址来源多样化**：
   - 取指令和读立即数时，地址由 PC 提供
   - 写存储器时，地址由寄存器（经过 MAR）提供

5. **控制信号协调**：存储器的读写由 MEM_WR 信号控制，而数据是否输出到总线由 MEM_GATE_EN 控制，两者配合实现正确的数据通路。

### （3）指令执行过程观察

**存储器读指令 `mov a, [r0]` 的执行过程：**

1. **取指阶段**：
   - PC 指向指令地址，取出指令机器码
   - 指令译码，确定为寄存器间接寻址的读存储器操作

2. **取地址阶段**：
   - 微指令将 r0 的值（0x20）传送到 MAR（地址寄存器）

3. **读存储器阶段**：
   - MAR 的值输出到地址总线 ABUS
   - MEM_WR=1（读），MEM_GATE_EN=0（输出门打开）
   - 存储器输出地址 0x20 单元的内容
   - 数据通过数据总线传送到累加器 A
   - 时钟上升沿，数据写入 A

**存储器写指令 `mov [r0], a` 的执行过程：**

1. **取指阶段**：同上

2. **取地址阶段**：
   - 微指令将 r0 的值传送到 MAR

3. **写存储器阶段**：
   - MAR 的值输出到地址总线 ABUS
   - 累加器 A 的值输出到数据总线 DBUS
   - MEM_WR=0（写），准备写入
   - 时钟上升沿，数据写入存储器地址 0x20 单元

### （4）存储器访问控制信号

| 操作类型 | MEM_WR | MEM_GATE_EN | 地址来源 | 数据流向 |
|:--------:|:------:|:-----------:|:--------:|:---------|
| 取指令 | 1 | 0 | PC | RAM→DBUS→IR |
| 读立即数 | 1 | 0 | PC | RAM→DBUS→寄存器 |
| 读存储器 | 1 | 0 | MAR/Rx | RAM→DBUS→寄存器 |
| 写存储器 | 0 | 1 | MAR/Rx | 寄存器→DBUS→RAM |

**结论：**
- MEM_WR 决定读写方向：1=读，0=写
- MEM_GATE_EN 控制输出门：只在读操作时打开（0）
- 地址来源：取指令/读立即数用 PC，访问存储器用 MAR
- 数据流向：读操作从 RAM 到寄存器，写操作从寄存器到 RAM

## 2、数据总线冲突分析

### （1）DM1000 中挂接到数据总线 DBUS 上的总线收发器

DM1000 中挂接到数据总线 DBUS 上的总线收发器包括：

| 总线收发器 | 方向 | 功能 |
|:----------:|:----:|:-----|
| MEM_gate | 发送 | 存储器 RAM 输出到数据总线 |
| D_gate | 发送 | ALU 运算结果输出到数据总线 |
| REG_gate | 发送 | 寄存器模块输出到数据总线 |
| RIN_gate | 发送 | 输入寄存器 RIN 输出到数据总线 |
| IR_gate | 接收 | 指令寄存器 IR 从数据总线接收 |
| A_REG | 接收 | 累加器 A 从数据总线接收 |
| W_REG | 接收 | 工作寄存器 W 从数据总线接收 |
| Rx_REG | 接收 | 通用寄存器从数据总线接收 |

### （2）控制单元 CU 如何控制总线收发器

控制单元 CU 通过 **X3、X2、X1、X0** 四位二进制编码来控制总线收发器的使能：

| X3 X2 X1 X0 | 使能的总线收发器 | 操作 |
|:-----------:|:----------------:|:----:|
| 0000 | - | 无 |
| 0001 | MEM_gate | 存储器读 |
| 0010 | D_gate | ALU 输出 |
| 0011 | REG_gate | 寄存器输出 |
| 0100 | RIN_gate | 输入寄存器输出 |
| ... | ... | ... |

**控制原理：**
1. 任何时刻，最多只能有一个发送型总线收发器向数据总线发送数据，避免信号冲突
2. 可以有多个接收型总线收发器同时从数据总线接收数据
3. CU 根据当前执行的微指令，通过编码 X3X2X1X0 决定哪个发送型总线收发器使能
4. 同时，CU 通过其他控制信号（如 A_REG_EN、W_REG_EN 等）决定哪些寄存器接收数据

### （3）存储器读写时的总线控制

**读存储器时：**
- X3X2X1X0 = 0001，使能 MEM_gate
- MEM_gate 将存储器 RAM 的输出送到数据总线
- 目的寄存器的使能信号有效（如 A_REG_EN=0），从总线接收数据

**写存储器时：**
- X3X2X1X0 使能数据源（如 0010 使能 D_gate，或 0011 使能 REG_gate）
- 数据源将数据送到数据总线
- 存储器 MEM_WR=0，在时钟上升沿将总线上的数据写入

# 七、扩展思考

## 1、为什么 DM1000 的存储器 RAM 输入数据总线与输出数据总线是同一条？

答：DM1000 使用双向数据总线 DBUS 来连接存储器和 CPU 的各个模块。这种设计有以下优点：

（1）**简化电路结构**：使用双向总线可以减少引脚数量，降低电路复杂度。

（2）**节省资源**：不需要分别为输入和输出设计独立的数据通路。

（3）**控制简便**：通过 MEM_WR 和 MEM_GATE_EN 等控制信号的配合，可以确保在任一时刻总线上只有一个数据源在发送数据，避免冲突。

具体工作方式：
- 读操作时：MEM_WR=1，MEM_GATE_EN=0，存储器数据输出到总线
- 写操作时：MEM_WR=0，MEM_GATE_EN=1，外部数据输入到存储器

## 2、如果存储器容量扩大到 64KB，需要做哪些改动？

答：将存储器容量从 256 字节扩大到 64KB（65536 字节），需要做以下改动：

（1）**地址线扩展**：
- 原地址线：8 位（ABUS[7..0]）
- 新地址线：16 位（ABUS[15..0]）
- 需要增加 8 根地址线

（2）**PC 寄存器扩展**：
- 原 PC：8 位
- 新 PC：16 位
- 需要修改 PC 模块的位宽

（3）**指令集调整**：
- 直接寻址的指令需要 2 字节表示地址（原为 1 字节）
- 部分指令的机器码格式可能需要调整

（4）**MAR 寄存器扩展**：
- 地址寄存器 MAR 需要从 8 位扩展到 16 位

（5）**微指令调整**：
- 涉及地址传送的微指令需要修改为 16 位操作

# 八、附录

## 1、存储器 RAM 功能说明

RAM 是 DM1000 的主存储器，用于存储指令和数据。

**主要特性：**
- 存储容量：256 字节
- 地址线宽度：8 位（可寻址 00~FF）
- 数据线宽度：8 位
- 读写控制：MEM_WR 信号控制，低电平写，高电平读
- 时钟触发：写操作在时钟上升沿触发
- 输出控制：MEM_GATE_EN 控制输出门，低电平有效

**读写时序参数：**
- 读访问时间：即时输出（组合逻辑）
- 写建立时间：地址和数据在时钟上升沿前稳定
- 写保持时间：地址和数据在时钟上升沿后保持

## 2、MEM 模块端口详细说明

| 端口名称 | 位宽 | 方向 | 有效电平 | 功能说明 |
|:--------:|:----:|:----:|:--------:|:---------|
| ABUS | 8 | 输入 | - | 地址总线，提供访问存储器的 8 位地址 |

| MEM_WR | 1 | 输入 | 低电平写 | 读写控制信号：1=读，0=写 |
