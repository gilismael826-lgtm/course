# 二、实验原理

## 2.1 算术逻辑运算单元（ALU）

算术逻辑运算单元（ALU）74LS181 是一种功能较强的组合逻辑电路，它能进行多种算术运算和逻辑运算。它的基本逻辑结构是超前进位加法器。

### 主要引脚功能：

- **S3~S0**：工作方式选择端，用于选择不同的运算功能
- **M**：运算模式选择，M=1 时进行逻辑运算，M=0 时进行算术运算
- **A=A3~A0, B=B3~B0**：参加运算的两个 4 位操作数
- **F=F3~F0**：运算结果输出
- **CN**：最低位进位输入，CN=1 时无进位，CN=0 时有进位
- **CN4**：最高位进位输出，低电平有效
- **AEQB**：当 F3~F0 全为高电平时为 1，否则为 0

### 74LS181 真值表（部分常用运算）：

| S3 S2 S1 S0 | M=1 逻辑运算 | M=0 算术运算(CN=1) | M=0 算术运算(CN=0) |
|-------------|-------------|-------------------|-------------------|
| 0 0 0 0 | F=/A(非) | F=A(直传) | F=A 加 1 |
| 0 0 0 1 | F=/(A+B) | F=A+B | F=(A+B)加 1 |
| 0 1 1 0 | F=A⊕B(异或) | F=A 减 B 减 1 | F=A 减 B |
| 1 0 0 1 | F=A⊕B | F=A 加 B | F=A 加 B 加 1 |
| 1 0 1 1 | F=AB(与) | F=AB 减 1 | F=AB |
| 1 1 1 0 | F=A+B(或) | F=(A+/B)加 A | F=(A+/B)加 A 加 1 |
| 1 1 1 1 | F=A(直传) | F=A 减 1 | F=A(直传) |

## 2.2 DM1000 中的 ALU 模块

DM1000 中的 ALU 模块由以下部分组成：

1. **两片 74LS181 串行进位扩展成 8 位算术逻辑运算器**：通过将两片 4 位 ALU 芯片串联，实现 8 位数据的运算功能

2. **累加器 A 和工作寄存器 W**：
   - 输入端直接与数据总线相连
   - 在使能信号和时钟控制下，可将数据总线上的数据写入寄存器
   - 输出分别作为 ALU 的两个 8 位运算数

3. **直通门 D_gate**：用于输出 ALU 的运算结果到数据总线

4. **控制信号**：通过不同的控制信号组合，指定 ALU 执行不同的运算操作

## 2.3 ALU 运算过程

要使 ALU 完成运算任务，需要以下步骤：

1. 将第一运算数写入累加器 A
2. 将第二运算数写入工作寄存器 W
3. 通过控制信号 S3~S0、M、CN 指定运算类型
4. ALU 执行运算并通过直通门输出结果
5. 将运算结果写回目的操作数寄存器

## 2、实验任务二：减法指令执行过程观察

### （1）实验任务描述

使用 DM1000 完成一个减法运算，观察减法指令的执行过程，理解控制单元 CU 如何控制 ALU 进行减法运算。

### （2）实验步骤

1. 打开项目下的汇编源程序文件 ram.asm；

2. 编写减法运算程序：

```asm
.text          ; 代码段
mov r0, -1     ; 将立即数 -1 写入寄存器 r0
mov a, 5       ; 将立即数 5 写入累加器 A
sub a, r0      ; 执行 A - r0 运算，即 5 - (-1) = 6
```

3. 编译汇编程序，生成机器指令；

4. 加载指令程序到 DM1000 模型机；

5. 启动仿真，使用单步执行功能观察减法指令的执行过程；

6. 观察并记录：
   - 取指阶段：指令如何从存储器取出并送入指令寄存器 IR
   - 执行阶段：操作数如何从寄存器传送到 ALU
   - 运算阶段：ALU 如何执行减法运算
   - 写回阶段：运算结果如何写回累加器 A

### （3）减法指令执行过程分析

减法指令 `sub a, r0` 的执行过程：

1. **取指阶段**：
   - PC 指向存储器中的减法指令
   - 指令机器码被取出并送入指令寄存器 IR
   - 指令译码，确定需要执行减法运算

2. **取操作数阶段**：
   - 将累加器 A 的值（5）传送到 ALU 的第一输入端
   - 将寄存器 r0 的值（-1 的补码 0xFF）传送到 ALU 的第二输入端

3. **运算阶段**：
   - 控制单元输出控制信号：M=0（算术运算），S3~S0=0110（减法）
   - ALU 执行减法运算：5 - (-1) = 5 + 1 = 6
   - 运算结果 0x06 在 ALU 输出端就绪

4. **写回阶段**：
   - 运算结果通过数据总线写回累加器 A
   - 标志寄存器更新（零标志、进位标志等）

5. **PC 更新**：
   - PC 加 1，指向下一条指令

### （4）实验任务总结

通过观察减法指令的执行过程，得出以下结论：

1. **指令执行分阶段**：一条指令的执行分为取指、译码、执行、写回等多个阶段，每个阶段对应一条或多条微指令。

2. **微指令控制**：控制单元 CU 通过输出不同的控制信号（微指令），控制数据在 ALU、寄存器、存储器等模块之间的流动。

3. **数据通路**：减法运算的数据通路为：寄存器 → ALU → 寄存器，控制信号决定数据流动的方向和运算类型。

4. **补码运算**：减法运算通过补码转换为加法运算实现，ALU 的减法功能实际上是 A + (~B) + 1。

## 2、ALU 控制信号分析

### （1）来自 CU 的控制信号

在 ALU 模块中，以下输入信号由**控制单元 CU**发出：

| 信号名称 | 位宽 | 功能说明 |
|---------|------|---------|
| `S3, S2, S1, S0` | 4位 | ALU 功能选择，决定进行何种运算 |
| `M` | 1位 | 运算模式：M=0 算术运算，M=1 逻辑运算 |
| `CN` | 1位 | 最低位进位输入：CN=1 无进位，CN=0 有进位 |
| `A_REG_EN` | 1位 | 累加器 A 写使能，低电平有效 |
| `W_REG_EN` | 1位 | 工作寄存器 W 写使能，低电平有效 |
| `D_GATE_EN` | 1位 | ALU 输出直通门使能，低电平有效 |

### （2）控制信号作用详解

**① 运算控制信号（S3~S0, M, CN）**

这三个信号共同决定 ALU 的运算类型：
- `M` 区分算术/逻辑运算
- `S3~S0` 在每种模式下选择16种具体运算之一
- `CN` 在算术运算时控制进位

**② 寄存器控制信号（A_REG_EN, W_REG_EN）**

- `A_REG_EN=0`（低电平）：使能累加器 A 写入，时钟上升沿时数据写入 A
- `W_REG_EN=0`（低电平）：使能工作寄存器 W 写入，时钟上升沿时数据写入 W

**③ 输出控制信号（D_GATE_EN）**

- `D_GATE_EN=0`（低电平）：打开 ALU 输出直通门，运算结果输出到数据总线
- `D_GATE_EN=1`（高电平）：关闭输出门，ALU 与总线隔离

### （3）指令执行过程中的信号变化

以 `ADD A, R0` 指令为例：

```
阶段1：取指
  - CU 发出取指微指令
  - ALU 控制信号：无变化（ALU 不工作）

阶段2：取操作数
  - 微指令：path rx, w
  - CU 发出：W_REG_EN=0
  - 结果：r0 的值写入工作寄存器 W

阶段3：ALU 运算
  - 微指令：path alu_add, a
  - CU 发出：
    * S3S2S1S0 = 1001（加法）
    * M = 0（算术运算）
    * CN = 1（无进位）
    * D_GATE_EN = 0（打开输出门）
    * A_REG_EN = 0（准备写入 A）
  - ALU 执行：A + W → F

阶段4：写回结果
  - 时钟上升沿
  - 运算结果从数据总线写入累加器 A
```

### （4）观察结果总结

| 指令 | S3 | S2 | S1 | S0 | M | CN | A_REG_EN | D_GATE_EN | 说明 |
|------|----|----|----|----|---|----|---------|----------|------|
| ADD | 1 | 0 | 0 | 1 | 0 | 1 | 0 | 0 | 算术加法 |
| SUB | 0 | 1 | 1 | 0 | 0 | 0 | 0 | 0 | 算术减法 |
| AND | 1 | 0 | 1 | 1 | 1 | - | 0 | 0 | 逻辑与 |
| OR | 1 | 1 | 1 | 0 | 1 | - | 0 | 0 | 逻辑或 |
| NOT | 0 | 0 | 0 | 0 | 1 | - | 0 | 0 | 逻辑取反 |

**关键理解：**
- CU 通过 **S3~S0、M、CN** 三个信号"告诉"ALU 做什么运算
- CU 通过 **A_REG_EN、W_REG_EN** 控制何时写入寄存器
- CU 通过 **D_GATE_EN** 控制运算结果何时输出到总线
- ALU 本身只负责运算，所有操作都由 CU 的控制信号指挥

# 七、扩展思考

## 1、如何利用 ALU 实现乘法和除法运算？

答：ALU 本身只能进行基本的算术和逻辑运算，乘法和除法需要通过多次加法或减法以及移位操作来实现：

**乘法实现**：
- 使用移位和加法相结合的方式
- 例如：A × B 可以通过将 A 左移并与部分积相加来实现
- 需要配合移位寄存器和多次 ALU 运算

**除法实现**：
- 使用移位和减法相结合的方式
- 例如：A ÷ B 可以通过从 A 中反复减 B 并计数来实现
- 或者使用更高效的移位减法算法

在实际的微处理器中，乘法和除法通常由专门的硬件电路实现，或者通过微程序控制 ALU 多次运算来完成。

## 2、ALU 的进位输出 CN4 有什么作用？

答：CN4（最高位进位输出）的作用包括：

（1）**多字节运算**：在进行多字节（超过 8 位）运算时，低字节 ALU 的 CN4 连接到高字节 ALU 的 CN，实现进位传递。

（2）**溢出判断**：CN4 与次高位进位异或可以判断有符号数运算是否溢出。

（3）**无符号数比较**：通过判断 CN4 可以比较两个无符号数的大小。

（4）**循环移位**：在移位运算中，CN4 可以用于实现带进位的循环移位。

- **CN4**：进位输出（低电平有效）
- **AEQB**：A 等于 B 输出
- **G、P**：超前进位输出
