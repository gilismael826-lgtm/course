## 详细笔记

### 一、从MDP到POMDP

#### 为什么需要POMDP？

| 特性 | MDP | POMDP |
|------|-----|-------|
| 状态可观测性 | 完全可观测 | 部分可观测 |
| 智能体知识 | 知道确切状态 | 只知道信念状态 |
| 最优策略依赖 | 仅依赖当前状态 | 依赖信念状态 |
| 现实性 | 理想化 | 真实世界 |

> **关键洞察**：真实世界就是一个POMDP！

#### POMDP的组成元素

POMDP在MDP基础上增加了**传感器模型**：

```
POMDP = MDP + 传感器模型
```

**形式化定义**：
- 状态集合 $S$
- 动作集合 $A(s)$
- **转移模型**：$P(s' \mid s, a)$
- **奖励函数**：$R(s, a, s')$
- **⭐ 传感器模型**：$P(e \mid s)$ —— 在状态 $s$ 下感知证据 $e$ 的概率

#### 示例：$4 \times 3$ 世界的POMDP版本

- 添加噪声传感器（以 $1-\varepsilon$ 准确率报告每个方向是否有墙）
- 使用DDN（动态决策网络）表示：引入传感器变量 $E_t$
- 传感器模型：$P(E_t \mid X_t)$

---

### 二、⭐⭐⭐ 信念状态（Belief State）

#### 定义

**信念状态 $b$** 是所有可能状态的概率分布：

$$b = \langle b(s_1), b(s_2), \ldots, b(s_n) \rangle$$

其中 $b(s)$ 表示智能体认为处于状态 $s$ 的概率。

#### 示例

$4 \times 3$ 世界的初始信念状态（9个非终止状态均匀分布）：

$$b = \left\langle \frac{1}{9}, \frac{1}{9}, \frac{1}{9}, \frac{1}{9}, \frac{1}{9}, \frac{1}{9}, \frac{1}{9}, \frac{1}{9}, \frac{1}{9}, 0, 0 \right\rangle$$

（最后两个0对应终止状态）

---

### 三、⭐⭐⭐ 信念状态更新（滤波）

#### FORWARD更新公式

给定：
- 当前信念状态 $b$
- 执行动作 $a$
- 观测到证据 $e$

新的信念状态：

$$b'(s') = \alpha P(e \mid s') \sum_s P(s' \mid s, a) b(s)$$

简写为：

$$b' = \alpha \cdot \text{FORWARD}(b, a, e)$$

其中 $\alpha$ 是归一化常数。

```mermaid
flowchart LR
    A[当前信念状态 b] --> B[执行动作 a]
    B --> C[观测证据 e]
    C --> D[FORWARD更新]
    D --> E[新信念状态 b']
    E --> A
```

#### 直观理解

1. **预测步骤**：$\sum_s P(s' \mid s, a) b(s)$ —— 根据动作预测新状态
2. **更新步骤**：$P(e \mid s')$ —— 根据观测调整概率
3. **归一化**：$\alpha$ —— 确保概率和为1

---

### 四、POMDP的决策周期

POMDP智能体的决策周期分解为3个步骤：

```
┌─────────────────────────────────────────────────────┐
│  1. 给定当前信念状态 b，执行动作 a = π*(b)           │
│  2. 观测感知 e                                       │
│  3. 更新信念状态：b ← FORWARD(b, a, e)，然后重复      │
└─────────────────────────────────────────────────────┘
```

> **关键洞察**：最优动作只依赖于智能体当前的信念状态，不依赖于实际状态！

---

### 五、⭐⭐⭐ 信念状态空间上的MDP

#### 核心定理

**POMDP可以转化为信念状态空间上的MDP**：

1. **信念状态转移模型**：
   $$P(b' \mid b, a) = \sum_e P(b' \mid e, a, b) P(e \mid a, b)$$

2. **信念状态奖励函数**：
   $$\rho(b, a) = \sum_s b(s) \sum_{s'} P(s' \mid s, a) R(s, a, s')$$

3. **观测概率**：
   $$P(e \mid a, b) = \sum_{s'} P(e \mid s') \sum_s P(s' \mid s, a) b(s)$$

#### 为什么这个转换有效？

- 信念状态总是可以被智能体观测到（根据定义）
- 因此，在信念状态空间上求解MDP等价于在原POMDP上求解
- 最优策略 $\pi^*(b)$ 将信念状态映射到动作

#### 挑战

信念状态空间是**连续的**！
- $4 \times 3$ 世界：11维连续空间
- 状态数 $|S|$ 的POMDP：$(|S|-1)$维概率单纯形

## 重点公式总结

| 公式名称 | 表达式 | 说明 |
|---------|--------|------|
| **信念更新** | $b'(s') = \alpha P(e \mid s') \sum_s P(s' \mid s, a) b(s)$ | FORWARD算法 |
| **信念转移** | $P(b' \mid b, a) = \sum_e P(b' \mid e, a, b) P(e \mid a, b)$ | 信念空间MDP |
| **期望奖励** | $\rho(b, a) = \sum_s b(s) \sum_{s'} P(s' \mid s, a) R(s, a, s')$ | 信念状态奖励 |
| **观测概率** | $P(e \mid a, b) = \sum_{s'} P(e \mid s') \sum_s P(s' \mid s, a) b(s)$ | 预测观测 |

---

## POMDP vs MDP 对比

| 方面 | MDP | POMDP |
|------|-----|-------|
| 状态空间 | 离散 | 连续（信念空间） |
| 策略形式 | $\pi(s)$ | $\pi(b)$ |
| 求解难度 | P-complete | PSPACE-hard |
| 信息价值 | 不考虑 | 内建于模型 |
| 典型算法 | 价值迭代、策略迭代 | 价值迭代、在线算法 |
