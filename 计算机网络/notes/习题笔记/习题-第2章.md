### 2-04 试解释以下名词：数据、信号、模拟数据、模拟信号、基带信号、带通信号、数字数据、数字信号、码元、单工通信、半双工通信、全双工通信、串行传输、并行传输。

#### 💡 解答

| 名词 | 解释 |
|:-----|:-----|
| 数据 | 运送信息的实体 |
| 信号 | 数据的电气或电磁的表现 |
| 模拟数据 | 取值连续的数据 |
| 模拟信号 | 参数取值连续的信号 |
| 基带信号 | 来自信源的原始信号，含较多低频分量 |
| 带通信号 | 经载波调制后频率搬移到高频段的信号 |
| 数字数据 | 取值离散的数据 |
| 数字信号 | 参数取值离散的信号 |
| 码元 | 代表不同离散数值的基本波形 |
| 单工通信 | 只能单向通信 |
| 半双工通信 | 双方可发送但不能同时发送 |
| 全双工通信 | 双方可同时发送和接收 |
| 串行传输 | 数据按位依次传送 |
| 并行传输 | 数据在多个信道上同时传送 |

### 2-08 假定要用3kHz带宽的电话信道传送64kbit/s的数据（无差错传输），试问这个信道应具有多高的信噪比（分别用比值和分贝来表示）？这个结果说明什么问题？

#### 💡 解答

**香农公式**：C = W × log₂(1 + S/N)

- 64000 = 3000 × log₂(1 + S/N)
- S/N ≈ 2,639,577
- 信噪比(dB) = 10log₁₀(2639577) ≈ 64.2 dB

#### 📋 答案汇总

| 项目 | 结果 |
|:-----|:-----|
| 信噪比（比值） | ≈ 2,639,577 |
| 信噪比（分贝） | ≈ 64.2 dB |
| 说明 | 信噪比很高，实际电话信道难以达到 |

### 2-09 用香农公式计算：假定信道带宽为3100Hz，最大信息传输速率为35kbit/s，那么若想使最大信息传输速率增加60%，问信噪比S/N应增大到多少倍？如果在刚才计算出的基础上将信噪比S/N再增大到10倍，问最大信息传输速率能否再增加20%？

#### 💡 解答

**第一问**：
- 目标速率：56 kbit/s
- 信噪比应增大到约 **100倍**

**第二问**：
- 信噪比再增大10倍
- 最大信息速率只能再增加约 **18.5%**

#### 📋 答案汇总

| 项目 | 结果 |
|:-----|:-----|
| 信噪比增大倍数 | ≈ 100倍 |
| 再增10倍后的速率增加 | ≈ 18.5%（不能达到20%）|

### 2-11 假定有一种双绞线的衰减是0.7dB/km（在1kHz时），若容许有20dB的衰减，试问使用这种双绞线的链路的工作距离有多长？如果要使这种双绞线的工作距离增大到100公里，问应当使衰减降低到多少？

#### 💡 解答

- 工作距离 = 20 / 0.7 ≈ 28.6 km
- 100km时衰减 = 20 / 100 = 0.2 dB/km

#### 📋 答案汇总

| 项目 | 结果 |
|:-----|:-----|
| 工作距离 | ≈ 28.6 km |
| 100km时衰减要求 | 0.2 dB/km |

### 2-13 为什么要使用信道复用技术？常用的信道复用技术有哪些？

#### 💡 解答

**目的**：提高信道利用率，允许多用户共享信道

**常用技术**：
- FDM（频分复用）
- TDM（时分复用）
- STDM（统计时分复用）
- WDM（波分复用）
- CDM（码分复用）

### 2-15 码分多址CDMA为什么可以使所有用户在同样的时间使用同样的频带进行通信而不会互相干扰？这种复用方法有何优缺点？

#### 💡 解答

**原理**：各用户使用互相正交的码片序列，接收端用内积运算分离信号

**优点**：抗干扰能力强、容量大、保密性好、功耗低
**缺点**：需功率控制、码序列管理复杂
