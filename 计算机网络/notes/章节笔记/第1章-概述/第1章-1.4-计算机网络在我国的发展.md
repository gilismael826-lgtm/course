## 重点内容

### ⭐ 核心概念

1. **1994年4月20日**：我国用64kbit/s专线正式连入互联网，被国际正式承认
2. **五大公用计算机网络**：CHINANET、UNINET、CMNET、CERNET、CSTNET
3. **2004年2月**：CERNET2试验网开通，标志中国达到国际先进水平
4. **CNNIC**：中国互联网络信息中心，每年两次发布统计报告

***

## 详细笔记

### 一、发展里程碑

| 时间 | 事件 | 意义 |
|:-----|:-----|:-----|
| 1980年 | 铁道部开始计算机联网实验 | 最早着手建设专用计算机广域网 |
| 1989年11月 | 第一个公用分组交换网**CNPAC**建成运行 | 我国第一个公用分组交换网 |
| 20世纪80年代后期 | 公安、银行、军队等部门建立专用广域网 | 迅速传递重要数据信息 |
| 20世纪80年代起 | 国内许多单位安装大量**局域网** | 价格便宜，便于开发、管理和维护 |
| **1994年4月20日** | 用64kbit/s专线正式连入互联网 | **被国际正式承认为接入互联网的国家** |
| 1994年5月 | 中科院高能物理研究所设立第一个万维网服务器 | 我国第一个WWW服务器 |
| 1994年9月 | **CHINANET**正式启动 | 中国公用计算机互联网 |
| 2004年2月 | **CERNET2**试验网正式开通 | 第一个下一代互联网，速率2.5~10Gbit/s |

> 1994年4月20日是**标志性日期**，考试常考。

### 二、五大公用计算机网络

| 缩写 | 全称 | 说明 |
|:-----|:-----|:-----|
| **CHINANET** | 中国电信互联网 | 原来的中国公用计算机互联网，规模最大 |
| **UNINET** | 中国联通互联网 | |
| **CMNET** | 中国移动互联网 | |
| **CERNET** | 中国教育和科研计算机网 | 教育和科研用途 |
| **CSTNET** | 中国科学技术网 | |

### 三、CERNET2（下一代互联网）

- **2004年2月**正式开通
- 速率：**2.5~10 Gbit/s**
- 连接北京、上海、广州三个CERNET核心节点
- 与国际下一代互联网相连接
- 标志中国达到**国际先进水平**

### 四、CNNIC统计信息

**CNNIC**（China Network Information Center，中国互联网络信息中心）：
- 每年两次公布我国互联网发展情况
- 网民定义：过去半年内使用过互联网的6周岁及以上中国居民

**截至2020年3月底**：
- 网民：**9.04亿**
- 互联网普及率：**64.5%**
- 手机网民：**8.97亿**（占总体网民99.3%+）
- 农村网民：2.55亿（占整体网民28.2%）
- 国际出口带宽：超过**8.8 Tbit/s**

**全球对比（2019年3月）**：
- 全世界互联网普及率：56.8%
- 北美：89.4%
- 欧洲：86.8%

### 五、国内主要互联网公司

| 时间 | 人物 | 公司/产品 | 特点 |
|:-----|:-----|:----------|:-----|
| 1996年 | 张朝阳 | 爱特信→**搜狐(Sohu)** | 中国首家大型分类查询搜索引擎 |
| 1997年 | 丁磊 | **网易(NetEase)** | 中国第一个中文全文搜索引擎，163/126邮箱 |
| 1998年 | 王志东 | **新浪(Sina)** | 全球最大中文综合门户网站 |
| 1998年 | 马化腾、张志东 | **腾讯(Tencent)** | QQ、微信，最大互联网综合服务提供商 |
| 2000年 | 李彦宏、徐勇 | **百度(Baidu)** | 全球最大中文搜索引擎 |
| 1999年 | 马云 | **阿里巴巴(Alibaba)** | B2B网上贸易市场 |
| 2003年 | 马云 | **淘宝(Taobao)** | 个人网上贸易市场 |
| 2004年 | 马云 | **支付宝(Alipay)** | 第三方支付平台 |

**微信(WeChat)**：
- 2011年推出，张小龙领导研发
- 支持话音短信、视频、图片、文字、多人视频会议
- 从社交工具演变成具有支付能力的全能钱包
