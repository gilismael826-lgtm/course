# 强制阅读大纲规则

## 规则说明

当用户询问任何与课本内容相关的问题时，**必须**先阅读对应科目的`大纲.md`文件，了解课程结构和重点内容。

---

## 执行流程

### 1. 识别科目
根据用户问题判断涉及的科目：
- **数据库原理** → `数据库原理/大纲.md`
- **计算机网络** → `计算机网络/大纲.md`
- **计算机组成原理** → `计算机组成原理/大纲.md`
- **软件工程** → `软件工程/大纲.md`
- **人工智能** → `人工智能上/大纲.md` 或 `人工智能下/大纲.md`
- **毛概/毛泽东思想** → `毛概/大纲.md`

### 2. 强制阅读大纲
在回答任何问题之前，**必须**执行：
```
Read: 对应科目/大纲.md
```

### 3. 分析大纲内容
阅读大纲后，分析：
- 用户问题涉及哪个章节
- 该章节的重点标记（⭐优先级）
- 相关的核心概念和知识点

### 4. 定位具体内容
根据大纲指引，在`full.md`中定位具体内容：
- 使用章节标题搜索
- 使用关键词搜索
- 参考大纲中的重点提示

### 5. 检测并读取插图
在定位到的内容中，**必须**检查是否包含图片引用：
- 图片引用格式：`![](images/xxx.jpg)` 或 `![描述](images/xxx.jpg)`
- 如果发现图片引用，**必须**读取对应的图片文件
- 使用Read工具读取图片：`Read: 科目名/images/图片文件名`

### 6. 分析图片内容
读取图片后，分析：
- 图片类型（流程图、示意图、表格、截图等）
- 图片展示的核心概念或过程
- 图片与文字内容的关联

### 7. 生成回答（必须指明出处）
基于大纲结构、文字内容和图片分析，生成完整回答。

**出处标注规则**：
- **课本内容**：只需标注章节位置
- **网上搜索内容**：必须标注"🌐 网上搜索"
- **图片**：如有引用图片，注明"见插图"

**出处格式示例**：
> 📚 **出处**：第2章 2.5节"关系模式的范式"
> 
> 🌐 **拓展**：网上搜索

6. 如果发现图片（如范式示例图），读取图片：`Read: 数据库原理/images/xxx.jpg`

   - 解释第三范式的定义
   - **添加出处**：📚 **出处**：第2章 2.5节"第三范式(3NF)"

## 出处标注规范

### 课本内容出处
只标注章节位置，不标注书名和作者：
```
📚 出处：第2章 2.5节"关系模式的范式"
```

### 网上搜索内容出处
必须明确标注：
```
🌐 拓展：网上搜索 - 相关内容描述
```

### 图片出处
如有引用图片：
```
📚 出处：第5章 5.9节"TCP的运输连接管理"，见插图
```

### 多个出处的情况
```
📚 主要出处：第2章 2.5节"关系模式的范式"
📖 参考出处：第3章 3.3节"逻辑结构设计"
🌐 拓展：网上搜索 - 实际应用案例
```

### 标注原则
- **课本内容**：只标章节（因为你知道是哪本书）
- **网上内容**：必须标"🌐 网上搜索"
- **混合内容**：分别标注来源

## 图片处理规则

### 图片识别
在`full.md`中，图片以Markdown格式嵌入：
```markdown
![](images/哈希值.jpg)
![图片描述](images/哈希值.jpg)
```

### 图片读取流程
1. **扫描内容**：在定位的文本中搜索`![](images/`或`![`模式
2. **提取路径**：提取图片相对路径（如`images/xxx.jpg`）
3. **构建完整路径**：`科目名/images/xxx.jpg`
4. **读取图片**：使用Read工具读取图片文件
5. **分析内容**：根据图片类型进行分析

### 图片类型分析
- **流程图**：描述步骤、过程、算法
- **示意图**：展示结构、架构、关系
- **表格**：展示数据、对比、分类
- **截图**：展示代码、界面、结果
- **图表**：展示趋势、统计、关系

### 图片与文字结合
- 图片展示的内容用文字描述
- 文字解释图片中的关键信息
- 结合两者给出完整答案
