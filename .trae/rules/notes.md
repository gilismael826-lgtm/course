# 课程笔记规则


## 笔记文件夹结构

笔记应按类型分类存放，每个课程的`notes`文件夹结构如下：

```
notes/
├── 章节笔记/           # 按章节组织的详细笔记
│   ├── 第4章-网络层/       # 按章创建子目录
│   │   ├── 第4章-网络层.md
│   │   ├── 第4章-4.1-网络层的几个重要概念.md
│   │   └── 第4章-4.2-网际协议IP.md
│   ├── 第5章-运输层/
│   │   ├── 第5章-运输层.md
│   │   ├── 第5章-5.1-TCP传输控制协议概述.md
│   │   └── 第5章-5.2-UDP用户数据报协议.md
│   └── ...
├── 专题笔记/           # 跨章节的专题深入笔记
│   └── 专题-XXX.md
├── 习题笔记/           # 习题解答和练习
│   └── 习题-第X章.md
├── 总结复习/           # 考试复习和知识点总结
│   └── 总结-XXX.md
└── README.md           # 笔记目录说明
```

**章节笔记组织方式**：
- 在`章节笔记/`下按章创建子目录，命名为`第X章-章节标题/`
- 每章的笔记文件存放在对应的子目录中
- 便于按章节管理和查找笔记

## 笔记文件命名规范

### 1. 章节笔记（存放于`章节笔记/`文件夹）
- **完整章节**：`第X章-章节标题.md`
  - 示例：`第5章-对抗搜索和博弈.md`
- **小节笔记**：`第X章-节号-节标题.md`
  - 示例：`第5章-5.2-博弈中的优化决策.md`
  - 示例：`第5章-5.3-启发式αβ树搜索.md`

### 2. 专题笔记（存放于`专题笔记/`文件夹）
- **格式**：`专题-主题名称.md`
- **示例**：
  - `专题-移动顺序与αβ剪枝优化.md`
  - `专题-TCP拥塞控制.md`
  - `专题-贝叶斯网络推理`

### 3. 习题笔记（存放于`习题笔记/`文件夹）
- **格式**：`习题-第X章.md` 或 `习题-主题.md`
- **示例**：
  - `习题-第5章.md`
  - `习题-概率计算.md`

### 4. 总结复习（存放于`总结复习/`文件夹）
- **格式**：`总结-类型.md`
- **示例**：
  - `总结-第5章-对抗搜索和博弈.md`
  - `总结-考试重点.md`
  - `总结-知识点归纳.md`
  - `总结-公式大全.md`

## 笔记内容格式

### 文件头部模板
```markdown
# 笔记标题

## 基本信息
- **课程**：课程名称
- **章节**：第X章 章节名（或专题名称）
- **日期**：YYYY-MM-DD
- **标签**：#标签1 #标签2 #标签3

## 重点内容

## 详细笔记

## 疑问与思考

## 相关链接
```

### 内容规范

1. **使用Markdown格式**：标题、列表、表格、代码块等
2. **重点标记**：
   - ⭐ 重要概念
   - ⭐⭐⭐ 核心重点（考试必考）
   - ❓ 疑问/待解决
   - 💡 个人理解/技巧
   - 📌 考试重点
   - ⚠️ 常见误区
3. **插入图片**：使用相对路径 `../images/xxx.jpg`
4. **重要插图**：课本中的关键插图必须放入笔记中，帮助理解核心概念
5. **公式**：使用LaTeX格式 `$公式$` 或 `$$公式$$`
6. **图表**：优先使用mermaid绘制流程图和示意图

## 笔记分类指南

| 笔记类型 | 存放位置 | 内容特点 | 创建时机 |
|---------|---------|---------|---------|
| **章节笔记** | `章节笔记/第X章-章节标题/` | 按课本章节顺序，系统记录知识点 | 学习每一章时 |
| **小节笔记** | `章节笔记/第X章-章节标题/` | 针对重要小节的深入笔记 | 小节内容较多或重要时 |
| **专题笔记** | `专题笔记/` | 跨章节的重要概念深入分析 | 需要深入理解某个主题时 |
| **习题笔记** | `习题笔记/` | 课后习题解答、练习题 | 完成习题后 |
| **章节总结** | `总结复习/` | 单章知识点归纳 | 完成一章学习后 |
| **考试总结** | `总结复习/` | 多章综合、考试重点 | 复习备考时 |

## 笔记更新原则

1. **及时性**：课后24小时内整理笔记
2. **完整性**：包含概念、原理、例题、个人理解
3. **可追溯**：记录疑问和后续解答
4. **关联性**：建立知识点之间的链接
5. **分类存放**：按本规则放入对应文件夹
