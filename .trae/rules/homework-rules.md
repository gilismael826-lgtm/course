# 习题答题规则

## 适用范围

本规则适用于所有课程习题的解答过程。

---

## 答题流程

### 步骤1：查阅课本知识点

**操作要求：**
- 根据习题涉及的知识点，定位相关章节笔记
- 读取课本相关内容，确认概念和公式
- 如有例题，参考例题的解答方法

**文件定位：**
- 章节笔记路径：`notes/章节笔记/第X章-章节标题/`
- 优先读取：`第X章-网络层.md` 或相关小节笔记

### 步骤2：联网验证答案

**操作要求：**
- 使用 WebSearch 工具搜索相关知识点
- 验证答案的准确性
- 确认解题方法和结果

**搜索关键词示例：**
- "IP数据报分片 片偏移计算"
- "CIDR地址聚合 最长前缀匹配"
- "子网划分 主机数计算"

### 步骤3：作答方式

**对话框中（对用户）：**
- 给出详细解答过程
- 包含分析思路、计算步骤、关键知识点
- 用表格或列表清晰呈现结果

**文档中（记录答案）：**
- 不写详细分析过程
- 直接给出最终答案
- 按简洁格式输出

**示例（文档记录格式）：**

❌ 文档中不要这样写：
```
首先，我们需要计算每个分片的数据长度...
然后，根据MTU限制...
所以答案是...
```

✅ 文档中应该这样写：
```
| 分片 | 数据长度 | 片偏移 | MF |
|:----:|:--------:|:------:|:--:|
| 1 | 1480 | 0 | 1 |
| 2 | 1480 | 185 | 1 |
| 3 | 1020 | 370 | 0 |
```

---

## 答案格式规范

### 计算题
- 给出关键计算步骤（简要）
- 用表格或列表呈现结果
- 标注最终答案

### 分析题
- 分点列出要点
- 每个要点简洁明了
- 不超过3句话

### 画图题
- 使用 mermaid 绘制
- 标注关键参数
- 保持图形简洁

---

## 记录到文档

**操作要求：**
- 将答案追加到习题笔记文件
- 使用标准格式：

```markdown
#### 💡 解答

[简洁答案]

#### 📋 答案汇总

[最终答案表格/列表]
```

## 快速参考

### 常见题型答题模板

**IP分片题：**
```markdown
| 分片 | 总长度 | 数据长度 | 片偏移 | MF |
|:----:|:------:|:--------:|:------:|:--:|
```

**地址聚合题：**
```markdown
聚合后地址块：**XXX.XXX.XXX.XXX/XX**
```

**子网划分题：**
```markdown
| 子网 | 地址块 | 最小地址 | 最大地址 |
|:----:|:-------|:---------|:---------|
```

**路由表题：**
```markdown
| 目的网络 | 前缀匹配 | 下一跳 |
|:---------|:---------|:-------|
```
