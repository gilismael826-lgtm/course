## 重点内容

### ⭐⭐⭐ 核心区别
| 特性 | **冯·诺依曼结构** | **哈佛结构** |
|------|------------------|-------------|
| **存储器** | 指令和数据**共用**一个存储器 | 指令和数据**分开**存储 |
| **总线** | 1套总线（分时复用） | 2套独立总线 |
| **并行性** | ❌ 不能同时取指令和取数据 | ✅ 可以同时取指令和取数据 |
| **速度** | 较慢（总线瓶颈） | 较快（并行访问） |
| **硬件复杂度** | 简单 | 复杂 |
| **成本** | 低 | 高 |
| **PC连接** | PC → AR → 存储器 | PC 直连指令存储器 |

### ⭐⭐ 易混淆点
- **双总线冯·诺依曼 ≠ 哈佛结构**
  - 双总线冯·诺依曼：1个存储器 + 2条内部总线（不能并行取指令和数据）
  - 哈佛结构：2个存储器 + 2套独立总线（可以并行取指令和数据）

## 详细笔记

### 一、冯·诺依曼结构（Princeton Architecture）

#### 1. 基本概念
1945年由冯·诺依曼提出，是现代计算机的基础架构。

#### 2. 核心特点
- 指令和数据以二进制形式表示
- 采用**存储程序**方式
- 计算机由五大部件组成：运算器、控制器、存储器、输入设备、输出设备
- 指令由操作码和地址码组成

#### 3. 结构图示

```
┌─────────────────────────────────────────┐
│              CPU                        │
│   ┌─────┐    ┌─────┐                   │
│   │ PC  │───→│ AR  │                   │
│   └─────┘    └──┬──┘                   │
│                 │                       │
└─────────────────┼───────────────────────┘
                  │  地址总线+数据总线
                  ↓
           ┌─────────────┐
           │   存储器M    │
           │ (指令+数据)  │
           └─────────────┘
```

#### 4. 工作流程
```
时钟周期1：取指令
   PC → AR → 存储器 → 指令 → IR
   
时钟周期2：取数据（如果需要）
   地址 → AR → 存储器 → 数据 → DR
   
⚠️ 不能同时进行！
```

#### 5. 优缺点
| 优点 | 缺点 |
|------|------|
| 结构简单，成本低 | 不能并行取指令和数据 |
| 灵活性高，程序可自修改 | 总线成为瓶颈（冯·诺依曼瓶颈） |
| 设计成熟，广泛应用 | 速度受限 |

---

### 二、哈佛结构（Harvard Architecture）

#### 1. 基本概念
将程序指令存储器和数据存储器分开的架构。

#### 2. 核心特点
- 独立的**程序存储器空间**和**数据存储器空间**
- 每个存储器空间**独立编址**
- 使用**独立的系统总线**
- 4套总线：程序地址总线、程序数据总线、数据地址总线、数据数据总线

#### 3. 结构图示

```
┌─────────────────────────────────────────┐
│              CPU                        │
│   ┌─────┐         ┌─────┐              │
│   │ PC  │────────→│ AR  │              │
│   └──┬──┘         └──┬──┘              │
│      │               │                  │
│   指令地址总线    数据地址总线            │
│      │               │                  │
│      ↓               ↓                  │
│   ┌─────────┐    ┌─────────┐            │
│   │指令存储器│    │数据存储器│            │
│   └────┬────┘    └────┬────┘            │
│        │              │                 │
│      指令数据总线   数据数据总线           │
│        │              │                 │
│        └──────┬───────┘                 │
│               ↓                         │
│            CPU执行                      │
└─────────────────────────────────────────┘
```

#### 4. 工作流程
```
时钟周期1：
   ├─→ PC → 指令存储器 → 取指令 → IR
   └─→ AR → 数据存储器 → 取数据 → DR
   
✅ 同时进行！
```

#### 5. 优缺点
| 优点 | 缺点 |
|------|------|
| 可以并行取指令和数据 | 硬件复杂度高 |
| 速度快，吞吐率高 | 成本高 |
| 安全性好（指令不易被修改） | 灵活性较低 |

---

### 三、改进的哈佛结构

#### 1. 特点
- 仍使用分离的程序存储器和数据存储器
- 将4套总线合并为2套（地址总线+数据总线）
- 2套总线由程序存储器和数据存储器**分时复用**
- 折中方案，平衡性能和成本

#### 2. 结构图示
```
┌─────────────────────────────────────────┐
│              CPU                        │
│   ┌─────┐         ┌─────┐              │
│   │ PC  │────────→│ AR  │              │
│   └──┬──┘         └──┬──┘              │
│      │               │                  │
│      └───────┬───────┘                  │
│              │  地址总线                 │
│              ↓                          │
│        ┌─────────┐                      │
│        │ 多路选择器 │                     │
│        └───┬───┬──┘                     │
│            ↓   ↓                        │
│      ┌────────┐ ┌────────┐              │
│      │指令存储器│ │数据存储器│              │
│      └───┬────┘ └───┬────┘              │
│          └────┬─────┘                   │
│               │  数据总线                 │
│               ↓                         │
│              CPU                        │
└─────────────────────────────────────────┘
```

---

### 四、三种结构对比总结

| 结构 | 存储器 | 总线 | 并行性 | 应用 |
|------|--------|------|--------|------|
| **冯·诺依曼** | 1个（统一） | 1套 | ❌ 不能并行 | 通用计算机主存 |
| **哈佛** | 2个（分离） | 4套 | ✅ 完全并行 | DSP、嵌入式 |
| **改进哈佛** | 2个（分离） | 2套 | ⚠️ 部分并行 | 大多数现代处理器 |

---

### 五、现代计算机的混合使用

```
现代高性能计算机：
┌─────────────────────────────────────────┐
│  Cache层：采用哈佛结构                   │
│  ├─ 指令Cache（I-Cache）                │
│  └─ 数据Cache（D-Cache）                │
│         ↓                               │
│  主存层：采用冯·诺依曼结构                │
│  └─ 统一的存储空间                       │
└─────────────────────────────────────────┘
```

**为什么这样设计？**
- Cache层：需要高速并行访问 → 用哈佛结构
- 主存层：需要大容量和灵活性 → 用冯·诺依曼结构

---

### 六、易混淆概念辨析

#### 1. 双总线冯·诺依曼 vs 哈佛结构

| 特征 | 双总线冯·诺依曼 | 哈佛结构 |
|------|----------------|---------|
| 存储器数量 | 1个 | 2个 |
| 总线用途 | A、B总线都用于数据传输 | 指令总线、数据总线分别传输 |
| 能否同时取指令和数据 | ❌ 不能 | ✅ 能 |
| 本质 | 冯·诺依曼（存储程序） | 哈佛（存储分离） |

**关键判断**：看有几个存储器！
- 1个存储器 = 冯·诺依曼（无论几条总线）
- 2个存储器 = 哈佛结构

#### 2. PC连接方式的区别

| 结构 | PC连接方式 | 原因 |
|------|-----------|------|
| 冯·诺依曼 | PC → AR → 存储器 | 共用存储器，需要AR缓冲 |
| 哈佛 | PC 直连指令存储器 | 指令存储器独立，可直接访问 |

## 核心考点

### ⭐⭐⭐ 必考内容

1. **三种结构的特点和区别**
   - 冯·诺依曼：统一存储，1套总线
   - 哈佛：分离存储，4套总线
   - 改进哈佛：分离存储，2套总线

2. **判断结构类型**
   - 看存储器数量（1个还是2个）
   - 看PC连接方式（直连还是通过AR）
   - 看总线用途（分时复用还是独立并行）

3. **现代计算机的应用**
   - Cache：哈佛结构
   - 主存：冯·诺依曼结构

1. **简答题**：比较哈佛结构和冯·诺依曼结构的优缺点
