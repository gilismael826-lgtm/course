## 各节知识点总结

### 4.1 指令系统的发展与性能要求

#### 指令系统的发展

| 阶段 | 年代 | 特点 |
|:-----|:-----|:-----|
| 第一代 | 1950s | 简单指令，定点加减、逻辑运算 |
| 第二代 | 1960s | 集成电路，指令丰富，系列计算机出现 |
| 第三代 | 1970s | CISC，指令多达几百条 |
| 第四代 | 1980s | RISC理念，精简高效 |

#### CISC vs RISC

| 特性 | CISC | RISC |
|:-----|:-----|:-----|
| 指令数量 | 多（数百条） | 少（几十条） |
| 指令长度 | 变长 | 固定 |
| 寻址方式 | 多样 | 简单 |
| 执行周期 | 不等长 | 单周期为主 |
| 访存指令 | 不限 | 只有取数/存数 |
| 代表 | x86 | ARM、MIPS、PowerPC |

#### 性能要求

| 要求 | 说明 |
|:-----|:-----|
| **完备性** | 指令足够丰富，不必用软件实现 |
| **有效性** | 程序执行速度快、占用空间小 |
| **规整性** | 对称性、匀齐性、一致性 |
| **兼容性** | 向上兼容，低档软件可在高档机上运行 |

### 4.2 指令格式

#### 指令基本结构

```
| 操作码字段 OP | 地址码字段 A |
```

#### 操作码设计

- 操作码位数决定指令数量：$n$ 位操作码最多 $2^n$ 条指令
- **扩展操作码**：通过特定编码模式实现操作码动态扩展

#### 地址码类型

| 类型 | 格式 | 特点 |
|:-----|:-----|:-----|
| **零地址** | OP | 操作数隐含（栈操作） |
| **一地址** | OP A | 单操作数（累加器） |
| **二地址** | OP A,B | 结果存目的地址 |
| **三地址** | OP A,B,C | 结果存第三地址 |

#### 指令字长度

| 类型 | 特点 | 适用 |
|:-----|:-----|:-----|
| **定长指令** | 硬件简单、译码快速、存储可能浪费 | RISC |
| **变长指令** | 存储高效、灵活、译码复杂 | CISC |

### 4.3 指令和数据的寻址方式

#### 指令寻址方式

| 方式 | 说明 |
|:-----|:-----|
| **顺序寻址** | PC自动+1（或加指令长度） |
| **跳跃寻址** | 由当前指令给出下条指令地址 |

#### 9种数据寻址方式

| 方式 | 算法 | 优点 | 缺点 |
|:-----|:-----|:-----|:-----|
| **隐含寻址** | 操作数在专用寄存器 | 无访存 | 数据范围有限 |
| **立即寻址** | 操作数 = A | 无访存 | 操作数幅值有限 |
| **直接寻址** | EA = A | 简单直观 | 地址范围有限 |
| **间接寻址** | EA = (A) | 地址范围大 | 多重访存 |
| **寄存器寻址** | EA = R | 无访存、速度快 | 寄存器数量有限 |
| **寄存器间接寻址** | EA = (R) | 地址范围大 | 额外访存 |
| **偏移寻址** | EA = A + (R) | 灵活 | 较复杂 |
| **段寻址** | 段基址 + 偏移量 | 便于模块化 | 需要段寄存器 |
| **堆栈寻址** | EA = 栈顶 | 无须给地址 | 需要堆栈指示器 |

#### 偏移寻址的三种形式

| 形式 | 专用寄存器 | 公式 | 特点 |
|:-----|:-----------|:-----|:-----|
| **相对寻址** | PC | EA = A + (PC) | 便于程序浮动 |
| **基址寻址** | 基址寄存器 | EA = A + (BR) | 面向系统（多道程序） |
| **变址寻址** | 变址寄存器 | EA = A + (IX) | 面向用户（数组访问） |

---

### 4.4 典型指令

#### 指令分类（8类）

| 类别 | 功能 |
|:-----|:-----|
| 数据传送指令 | 寄存器与主存之间的数据传送 |
| 算术运算指令 | 定点/浮点加减乘除 |
| 逻辑运算指令 | 与、或、非、异或、移位 |
| 程序控制指令 | 转移、子程序调用/返回 |
| I/O指令 | 外设数据传送 |
| 字符串处理指令 | 字符串传送、比较、查找 |
| 特权指令 | 系统资源管理（仅OS使用） |
| 其他指令 | 空操作、暂停、状态设置 |

#### RISC三大特点

1. **选取使用频率最高的简单指令**，指令条数少
2. **指令长度固定**，指令格式种类少，寻址方式种类少
3. **只有取数/存数指令访问存储器**，其余指令的操作都在寄存器之间进行

#### RISC vs CISC 性能比较

$$
P = I \times C \times T
$$

| 指标 | RISC | CISC |
|:-----|:-----|:-----|
| I（指令数比值） | 1.2~1.4 | 1 |
| C（平均周期数） | 1.3~1.7 | 4~6 |
| T（周期时间比值） | <1 | 1 |

> 💡 RISC指令数稍多，但每条指令执行周期少，综合来看效率更高。

### 4.5 ARM汇编语言

#### ARM寄存器

| 寄存器 | 名称 | 用途 |
|:-------|:-----|:-----|
| r0 ~ r12 | 通用寄存器 | 一般数据操作 |
| SP | 堆栈指针 | 指向堆栈顶部 |
| LR | 链接寄存器 | 保存返回地址 |
| PC | 程序计数器 | 指向下一条指令 |

#### ARM常用指令

| 类别 | 指令 | 示例 | 含义 |
|:-----|:-----|:-----|:-----|
| 算术运算 | ADD | `ADD r1,r2,r3` | r1 = r2 + r3 |
| 算术运算 | SUB | `SUB r1,r2,r3` | r1 = r2 - r3 |
| 数据传送 | LDR | `LDR r1,[r2,#20]` | r1 = Mem[r2+20] |
| 数据传送 | STR | `STR r1,[r2,#20]` | Mem[r2+20] = r1 |
| 数据传送 | MOV | `MOV r1,r2` | r1 = r2 |
| 逻辑运算 | AND | `AND r1,r2,r3` | r1 = r2 & r3 |
| 逻辑运算 | ORR | `ORR r1,r2,r3` | r1 = r2 \| r3 |
| 逻辑运算 | MVN | `MVN r1,r2` | r1 = ~r2 |
| 移位 | LSL | `LSL r1,r2,#10` | r1 = r2 << 10 |
| 移位 | LSR | `LSR r1,r2,#10` | r1 = r2 >> 10 |
| 比较 | CMP | `CMP r1,r2` | 设置条件标志 |
| 条件转移 | BEQ | `BEQ 25` | 等于则转移 |
| 无条件转移 | B | `B 2500` | 无条件跳转 |

#### ARM寻址方式特点

- 采用 **Load/Store 架构**：只有 LDR/STR 访问内存
- 算术/逻辑指令操作数都在寄存器中
- 基址+偏移寻址：`[rB, #offset]`
- PC相对寻址用于转移指令

#### 汇编到机器语言翻译要点

| 字段 | 位数 | 说明 |
|:-----|:-----|:-----|
| cond | 4位 | 条件码（14=无条件） |
| F | 1位 | 指令类型标志 |
| I | 1位 | 立即数标志 |
| opcode | 4-5位 | 操作码 |
| S | 1位 | 设置状态标志 |
| Rn | 4位 | 第一个源/基址寄存器 |
| Rd | 4位 | 目的寄存器 |
| operand 2 | 12位 | 第二个操作数/偏移量 |

## 重要公式汇总

| 公式 | 说明 |
|:-----|:-----|
| $2^n$ | n位操作码最多表示的指令数 |
| $P = I \times C \times T$ | RISC/CISC性能比较 |
| EA = A | 直接寻址 |
| EA = (A) | 间接寻址 |
| EA = (R) | 寄存器间接寻址 |
| EA = A + (R) | 偏移寻址 |
| EA = A + (PC) | 相对寻址 |
| EA = A + (BR) | 基址寻址 |
| EA = A + (IX) | 变址寻址 |

## 易混淆点对比

| 概念A | 概念B | 区别 |
|:------|:------|:-----|
| CISC | RISC | 指令多/复杂 vs 指令少/简单；变长 vs 定长；多种访存 vs 只有Load/Store访存 |
| 直接寻址 | 间接寻址 | EA=A vs EA=(A)；一次访存 vs 两次访存 |
| 寄存器寻址 | 寄存器间接寻址 | EA=R vs EA=(R)；无访存 vs 有访存 |
| 相对寻址 | 基址寻址 | 面向用户/程序浮动 vs 面向系统/多道程序 |
| 基址寻址 | 变址寻址 | BR由系统设定 vs IX由用户设定 |
| 定长指令 | 变长指令 | 硬件简单/译码快 vs 存储高效/灵活 |
| 算术移位 | 逻辑移位 | 符号位不动 vs 所有位一起移 |
| 条件转移 | 无条件转移 | 根据标志位判断 vs 直接跳转 |
