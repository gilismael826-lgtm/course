## 各节知识点总结

### 1.1 计算机的分类

| 比较内容 | 电子数字计算机 | 电子模拟计算机 |
|:---------|:---------------|:---------------|
| 数据表示 | 数字0和1 | 电压 |
| 计算方式 | 数字计数 | 电压组合和测量值 |
| 精度 | 高 | 低 |
| 逻辑判断 | 强 | 无 |

- **通用计算机**：适应性强，PC、工作站、服务器
- **专用计算机**：效率高，嵌入式系统

### 1.2 计算机的发展简史

```mermaid
flowchart LR
    A[第一代<br/>电子管] --> B[第二代<br/>晶体管]
    B --> C[第三代<br/>集成电路]
    C --> D[第四代<br/>大规模集成电路]
    D --> E[第五代<br/>巨大规模集成电路]
```

**摩尔定律**：芯片上的晶体管数量大约每18个月翻一番。

| 国产处理器 | 架构 | 特点 |
|:-----------|:-----|:-----|
| 龙芯 | LoongArch | 自主架构 |
| 飞腾 | Arm | 国防科大研发 |
| 鲲鹏920 | ARMv8-A | 华为，64核 |

### 1.3 计算机的硬件 ⭐⭐⭐

**五大部件**：

| 部件 | 功能 |
|:-----|:-----|
| **运算器(ALU)** | 算术运算和逻辑运算 |
| **存储器** | 存放程序和数据 |
| **控制器** | 控制整个计算过程 |
| **输入设备** | 将信息送入计算机 |
| **输出设备** | 将结果展示给人 |

> 💡 采用**二进制**的原因：电压高低、脉冲有无容易实现，设备最省。

### 1.4 计算机的软件

- **系统软件**：操作系统、编译程序、数据库管理系统
- **应用软件**：各类应用程序
- **软件与硬件的逻辑等价性**：任何操作可由软件实现，也可由硬件实现

### 1.5 计算机系统性能评价 ⭐⭐⭐

| 指标 | 含义 |
|:-----|:-----|
| **吞吐量** | 单位时间处理的信息量 |
| **响应时间** | 输入到系统响应的时间 |
| **主频** | 单位时间内的时钟脉冲数 |
| **CPI** | 每条指令的平均时钟周期数 |
| **MIPS** | 每秒百万条指令 |
| **FLOPS** | 每秒浮点运算次数 |

**核心公式**：

$$
\text{CPU执行时间} = \frac{\text{指令数} \times \text{CPI}}{\text{时钟频率}}
$$

$$
\text{MIPS} = \frac{\text{时钟频率}}{\text{CPI} \times 10^6}
$$

### 1.6 计算机系统的层次结构 ⭐⭐⭐

#### 冯·诺依曼体系结构三大原则

1. **二进制表示**：指令和数据都用二进制
2. **存储程序**：程序存放在存储器中，自动执行
3. **五大部件**：运算器、控制器、存储器、输入设备、输出设备

> 💡 **存储程序**是冯·诺依曼体系结构的**核心**！

#### 哈佛结构 vs 冯·诺依曼结构

| 特性 | 冯·诺依曼结构 | 哈佛结构 |
|:-----|:--------------|:---------|
| 存储器 | 统一存储 | 分离存储 |
| 总线 | 1套总线 | 2套总线 |
| 并行性 | 不能并行取指令和数据 | 可以并行 |
| 应用 | 通用计算机 | 嵌入式系统、DSP |

**改进的哈佛结构**：2套总线（地址总线+数据总线），分时复用。

#### 计算机系统五级层次

| 层级 | 名称 | 执行方式 |
|:-----|:-----|:---------|
| 第5级 | 高级语言级 | 编译程序支持 |
| 第4级 | 汇编语言级 | 汇编程序支持 |
| 第3级 | 操作系统级 | 混合级 |
| 第2级 | 一般机器级 | 微程序解释执行 |
| 第1级 | 微程序设计级 | 硬件直接执行 |

## 重要公式汇总

| 公式 | 说明 |
|:-----|:-----|
| $CPU执行时间 = \frac{指令数 \times CPI}{时钟频率}$ | 计算程序执行时间 |
| $MIPS = \frac{时钟频率}{CPI \times 10^6}$ | 计算每秒百万条指令 |
| $CPU时钟周期数 = 指令数 \times CPI$ | 计算总时钟周期数 |

## 易混淆点对比

| 概念A | 概念B | 区别 |
|:------|:------|:-----|
| 冯·诺依曼结构 | 哈佛结构 | 统一存储/1套总线 vs 分离存储/2套总线 |
| 通用计算机 | 专用计算机 | 适应性强 vs 效率高 |
| 数字计算机 | 模拟计算机 | 0和1 vs 电压 |
| 系统软件 | 应用软件 | 管理/支持系统 vs 解决具体问题 |
| 微程序设计级 | 一般机器级 | 硬件直接执行 vs 微程序解释 |
