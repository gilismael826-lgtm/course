## 各节知识点总结

### 6.1 总线的概念和结构形态

#### 总线定义

总线是构成计算机系统的**互联机构**，是模块与模块之间传送信息的一组**公用信号线**。

#### 总线层次结构

| 层次 | 名称 | 连接对象 |
|:----:|:-----|:---------|
| 1 | 片内总线 | 处理器内部寄存器及运算部件 |
| 2 | 系统总线 | 处理器与存储器、通道 |
| 3 | I/O总线 | 主机与I/O设备 |
| 4 | 局部总线 | CPU私有存储器、高速外设 |

#### 总线四特性

| 特性 | 说明 |
|:-----|:-----|
| **物理特性** | 总线的物理连接方式（插头/插座形状、引脚数） |
| **功能特性** | 每根线的功能（数据线、地址线、控制线） |
| **电气特性** | 信号传递方向、电平范围 |
| **时间特性** | 信号的时序关系 |

#### 总线带宽公式

$$D_r = D \times f$$

- $D_r$：总线带宽（MB/s）
- $D$：总线宽度（字节）
- $f$：总线工作频率（MHz）

#### 单总线 vs 多总线

| 结构 | 优点 | 缺点 |
|:-----|:-----|:-----|
| 单总线 | 简单、易扩展 | 高低速设备共用，效率受限 |
| 多总线 | 效率高、吞吐量大 | 结构复杂 |

#### 当代总线内部结构

四部分：数据传送总线、仲裁总线、中断和同步总线、公用线

### 6.2 总线接口

#### 信息传送方式

| 方式 | 传输线数 | 速度 | 成本 | 适用场景 |
|:-----|:--------:|:----:|:----:|:---------|
| **串行** | 1条 | 慢 | 低 | 长距离通信 |
| **并行** | n条 | 快 | 高 | 系统总线 |

#### 串行传送特点

- 每次一位，低位在前，高位在后
- 需要**并→串变换（拆卸）**和**串→并变换（装配）**
- 由同步脉冲确定位时间

#### I/O接口六大功能

| 功能 | 说明 |
|:-----|:-----|
| **控制** | 靠指令控制外设动作（启动、关闭） |
| **缓冲** | 补偿设备间速度差异 |
| **状态** | 监视并保存外设状态（准备就绪、忙、错误） |
| **转换** | 完成数据转换（并→串、串→并） |
| **整理** | 修改字计数器或内存地址寄存器 |
| **程序中断** | 外设向CPU发中断请求 |

#### I/O接口分类

| 类型 | 说明 |
|:-----|:-----|
| 串行数据接口 | 外设以串行方式收发数据 |
| 并行数据接口 | 外设以并行方式收发数据 |

> CPU与I/O接口之间始终是**并行**；I/O接口与外设之间可能是串行或并行。

#### 波特率计算

- **波特率** = 每字符比特数 × 每秒字符数
- **位时间** = 1 / 波特率

### 6.3 总线仲裁

#### 基本概念

- **主方（主设备）**：可启动总线周期
- **从方（从设备）**：只能响应主方请求
- 每次总线操作只能有**一个主方**占用控制权

#### 仲裁信号

| 信号 | 全称 | 方向 | 作用 |
|:----:|:-----|:----:|:-----|
| **BR** | Bus Request | 设备→仲裁器 | 设备请求使用总线 |
| **BG** | Bus Grant | 仲裁器→设备 | 授权某设备使用总线 |
| **BS** | Bus Busy | 设备→仲裁器 | 表示总线正在被使用 |

#### 三种集中式仲裁方式对比

| 比较项 | 链式查询（菊花链） | 计数器定时查询 | 独立请求 |
|:-------|:-----------------|:-------------|:---------|
| 控制线数 | 2（BR, BG） | $\lceil \log_2 n \rceil + 2$ | $2n$（n对BR/BG） |
| 响应速度 | 慢（逐个查询） | 中等 | **快**（并行判断） |
| 优先级灵活性 | 固定（离仲裁器近优先） | 较灵活（可从任意值开始） | **最灵活**（可程序设置） |
| 故障敏感性 | **敏感** | 不敏感 | 不敏感 |
| 应用 | 简单系统 | 中等系统 | **当代总线标准** |

#### 分布式仲裁

- 每个主设备有自己的**仲裁号（CN）**和仲裁器
- 竞争号取反后打到仲裁总线AB上，实现**线或**逻辑
- CN与AB逐位比较（b₇→b₀），b₇为最高位优先比较
- 比较规则：CNᵢ=1 → 赢；CNᵢ=0且ABᵢ=1 → 赢；CNᵢ=0且ABᵢ=0 → 输退出
- **竞争号越大，优先级越高**

#### 二维仲裁

独立请求 + 菊花链查询相结合：每个BRᵢ/BGᵢ对可被多个设备共享，BG串行查询该组内各设备。

### 6.4 总线的定时和数据传送模式

#### 总线信息传送五个阶段

1. 请求总线
2. 总线仲裁
3. 寻址（目的地址）
4. 信息传送
5. 状态返回（或错误报告）

#### 四种定时方式对比

| 比较项 | 同步 | 异步 | 半同步 | 周期分裂 |
|:-------|:-----|:-----|:-------|:---------|
| 时钟信号 | 需要 | 不需要 | 需要 | 需要 |
| 总线周期 | 固定 | 可变 | 可变（插入T_w） | 可变（中间释放总线） |
| 控制方式 | 时钟边沿触发 | 应答/互锁机制 | 时钟+READY信号 | 两次申请总线 |
| 复杂性 | 简单 | 较复杂 | 适中 | 最复杂 |
| 总线利用率 | 受最慢模块限制 | 较高 | 较高 | **最高** |
| 适用场景 | 模块速度相近 | 模块速度差异大 | 大部分快、少数慢 | 高性能系统 |

#### 同步定时

- 事件由总线时钟信号确定，总线周期固定
- 必须按**最慢模块**设计公共时钟
- 适用：总线短、各模块存取时间接近

#### 异步定时

- 基于应答式/互锁机制，无统一公共时钟
- 总线周期长度**可变**
- 读周期：CPU发地址+读命令 → 内存准备数据 → 内存发确认 → CPU读取
- 写周期：CPU同时发地址+数据 → 内存写入 → 内存发确认

#### 半同步定时

- 在同步基础上增加**READY（或nWAIT）**信号线
- T₃前沿检测READY：
  - 有效 → 正常进入T₄
  - 无效 → 插入等待周期T_w，直到READY有效

#### 周期分裂式定时

- 读周期拆成两个子周期：
  - 第一个：主方发地址+命令后**立即释放总线**
  - 第二个：从方重新申请总线，发送数据
- 读数据的双方都是总线主方

#### 数据传送模式

| 模式 | 说明 |
|:-----|:-----|
| **读/写** | 主方与从方之间的基本数据传送 |
| **块传送（猝发式）** | 只给起始地址，连续读写多个数据 |
| **写后读** | 同一地址先写后读，用于校验 |
| **读修改写** | 同一地址先读后写，原子操作，用于共享资源保护 |
| **广播** | 主方向多个从方同时写 |
| **广集** | 多个从方数据在总线上做AND/OR，检测多个中断源 |

### 6.5 PCI总线和PCIe总线

#### PCI总线特点

- 高带宽、与处理器无关的标准总线
- 同步定时协议、集中式仲裁策略
- **自动配置**能力（即插即用）
- 基本传输机制：**猝发式传送**

#### 隐藏式仲裁

在当前总线占用期间裁决下一次主方，不需要单独仲裁周期，提高效率。

#### PCIe相比PCI的改进

| 改进点 | PCI | PCIe |
|:-------|:----|:-----|
| 信号传输 | 单端对地 | **高速差分传输** |
| 传输方式 | 并行 | **串行** |
| 连接方式 | 共享总线 | **全双工端到端** |
| 通道数 | 固定 | x1~x32（灵活配置） |
| 时钟 | 单独传输 | **嵌入时钟** |

### 6.6 鲲鹏处理器的总线与互联

#### CoWoS封装

多晶片合封技术，"乐高架构"，组合灵活。

#### 片上网络组成

| 部件 | 功能 |
|:-----|:-----|
| 环总线 | 片上系统内部连接各设备 |
| SLLC | 连接多个超级集群的环总线 |
| 调度器 | I/O请求调度与汇聚 |
| 分发器 | 请求分发至正确设备 |
| Hydra接口 | 多芯片片间互联，支持cache一致性 |

#### 多芯片系统

4个片上系统组成标准4P服务器，片间通信带宽**240Gbit/s**。

## 易混淆点对比

| 概念A | 概念B | 区别 |
|:------|:------|:-----|
| 串行传送 | 并行传送 | 1条线逐位传 vs n条线同时传；慢vs快 |
| 同步定时 | 异步定时 | 时钟驱动 vs 应答驱动；周期固定 vs 可变 |
| 半同步定时 | 异步定时 | 仍有统一时钟+READY信号 vs 完全无时钟 |
| 链式查询 | 独立请求 | 串行逐个查询 vs 并行独立响应；慢vs快 |
| 计数器查询 | 链式查询 | 地址线寻址 vs 授权线串行；灵活vs固定 |
| 分布式仲裁 | 集中式仲裁 | 无中央仲裁器 vs 有中央仲裁器；竞争号比较 vs BR/BG |
| 单总线 | 多总线 | 结构简单vs复杂；效率低vs高 |
| PCI | PCIe | 并行共享总线 vs 串行全双工端到端；单端vs差分 |
| 读周期 | 写周期（异步） | 数据在命令之后出现 vs 数据与地址同时出现 |
| 猝发式传送 | 普通读/写 | 连续多数据 vs 单个数据 |
