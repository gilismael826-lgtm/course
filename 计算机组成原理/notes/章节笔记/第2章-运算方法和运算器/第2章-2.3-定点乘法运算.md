### 二、原码乘法 ⭐⭐⭐

#### 运算规则

$$
[x]_{原} = x_f x_{n-1}...x_0, \quad [y]_{原} = y_f y_{n-1}...y_0
$$

$$
[x \times y]_{原} = (x_f \oplus y_f) + (x_{n-1}...x_0) \times (y_{n-1}...y_0)
$$

**步骤**：
1. **符号位**：异或运算 $x_f \oplus y_f$
2. **数值部分**：绝对值相乘

#### 人工算法 vs 机器算法

```
    1 1 0 1  (被乘数)
  × 1 0 1 1  (乘数)
  ─────────
    1 1 0 1   ← 乘数最低位为1，写被乘数
   1 1 0 1    ← 左移1位
  0 0 0 0     ← 乘数位为0，写0
 1 1 0 1      ← 左移3位
─────────
1 0 0 0 1 1 1 1  (乘积)
```

**机器实现**：加法-移位操作

### 三、无符号数阵列乘法器 ⭐⭐⭐

#### 基本原理

$$
P = a \times b = \left(\sum_{i=0}^{m-1} a_i 2^i\right) \left(\sum_{j=0}^{n-1} b_j 2^j\right) = \sum_{i=0}^{m-1} \sum_{j=0}^{n-1} (a_i b_j) 2^{i+j}
$$

#### 结构组成

```
        a3   a2   a1   a0    (被乘数A)
      × b3   b2   b1   b0    (乘数B)
      ─────────────────
        a3b0 a2b0 a1b0 a0b0  ← b0=1时产生
      a3b1 a2b1 a1b1 a0b1    ← 左移1位
    a3b2 a2b2 a1b2 a0b2      ← 左移2位
  + a3b3 a2b3 a1b3 a0b3       ← 左移3位
  ───────────────────────
  p7   p6   p5   p4   p3   p2   p1   p0
```

#### 硬件实现

- **$n^2$个与门**：产生位积 $a_i b_j$
- **$n(n-1)$个全加器**：实现阵列加法
- **延迟时间**：$t_m = (8n - 4)T$

---

### 四、带符号数阵列乘法器

#### 结构

1. **对2求补器**：将补码转换为原码
2. **无符号数乘法阵列**
3. **对2求补器**：将结果转换为补码

#### 对2求补器

**功能**：求一个数的补码的相反数（$[-y]_{补}$）

**方法**：从最低位开始，找到第一个1，该位左边所有位取反

---

### 五、补码乘法（Booth算法）⭐⭐

#### 基本思想

通过分析乘数中连续的0或1，减少加法次数。

#### 运算规则

检查乘数的相邻两位 $y_i y_{i+1}$：

| $y_i$ | $y_{i+1}$ | 操作 |
|-------|-----------|------|
| 0 | 0 | 0串中间，仅右移 |
| 0 | 1 | 1串结尾，加被乘数后右移 |
| 1 | 0 | 1串开始，减被乘数后右移 |
| 1 | 1 | 1串中间，仅右移 |

---

## 疑问与思考

### 💡 个人理解
- **阵列乘法器的优势**：并行计算，速度快
- **原码乘法的特点**：符号位单独处理，数值部分用无符号乘法
- **Booth算法的优势**：遇到连续0或1时减少加法操作
